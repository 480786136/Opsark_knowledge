# 知识服务长期演进与一期约束

更新：2026-09-08。状态：长期约束与实现进度；下文未标完成的能力仍待开发。

代码更新：本项目独立管理页面、本地管理员、会话/CSRF 已实现；Admin 知识页面/代理已退役。以下资料归属、索引和生命周期改进仍是待办，并未因管理拆分而完成。运行状态见 [开发版说明](../../Opsark_admin/docs/独立系统开发版使用与验收.md)。

## 保留的基础

保留结构化入库、持久任务、模板草稿、人工审核、版本发布与检索，不从零重写。知识已独立拥有管理入口/鉴权/资料/API；Admin 管模型接入及后续平台业务，旧知识代理已退役。

知识处理可直接配置第三方 API，也可选择 Admin 转发接口，但不能强制依赖 Admin 在线。未配 Embedding 可使用关键词模式。当前整理没有大模型提炼、事实判断或自动合并。

## 数据模型演进（待实现）

| 领域 | 应明确的内容 |
| --- | --- |
| 资料归属 | 所有者、空间、可见范围；默认私有，不隐式公开 |
| 来源 | 来源类型、外部 ID/修订、发生时间、脱敏规则；不等于保存完整原始日志 |
| 来源关联 | 文档/版本与来源多对多，结论可追溯到证据 |
| 适用性 | 系统/软件版本范围、环境、验证时间/状态、失效与替代关系 |
| 内容版本 | 不可变审核内容、审核主体/时间，编辑与发布状态分离 |
| 索引构建 | 构建 ID、内容版本、模型/维度、切片规则、配置指纹、状态与激活指针 |

当前文档只关联单一来源；上传的软件版本未贯穿草稿元数据/检索过滤。字段和迁移在编码前细化，不能向当前拒绝未知字段的上传协议直接加入未支持内容。跨系统引用外部主体 ID，不共用用户表。

## 索引和数据库

已完成先行防护：发布指纹与 Worker 当前配置不一致时，在批次前后和落库前阻止发布，标 INDEX_CONFIG_MISMATCH，并保留旧发布版本。尚未完成独立构建配置快照/代次、后台重建与激活切换；不能把一致性检查当完整索引演进。

内容版本与索引代次分开。模型/切片变化可后台重建，验证后原子切换；旧索引按保留策略清理。检索应反映实际通道和索引覆盖，不能仅因查询向量生成成功就声称混合检索完整可用。

向量维度变化需要迁移或新索引存储，不能只改 .env。历史迁移需固定定义，避免当前 ORM create_all 或环境变化影响旧迁移。已有数据库需明确升级、备份和回滚方案。

当前约 1800 字符按行切片；Python 读取候选并排序，5 万片段是保护阈值，不是容量保证。生产应将权限/环境过滤、词法及向量候选检索下推数据库；按标题、步骤、代码块切片，防止命令与前提脱离。

建立中文运维评测集，覆盖版本差异、精确路径、无答案、权限负例；测命中率、引用正确性、延迟与降级率。是否增加独立向量库由实际规模决定。[pgvector 官方资料](https://github.com/pgvector/pgvector)

## 生命周期、权限与安全

每次上传、管理、检索、引用和删除都校验主体/资源权限；现有 scope/允许库与高权限内部 Token 不等于多租户。未来统一登录不能替代资源授权。

删除文档当前清理其版本/切片，但来源 JSON 仍在；来源需另外删除且保留无正文去重标记。目标：明确操作范围，分别规定来源、草稿、版本、索引、审计、缓存、备份的保留期。备份按政策到期清理，恢复后重放删除标记，不承诺点击删除即抹除全部副本。

旧版本引用在新版本发布后当前不可读。长期需明确“当前知识检索”与“受权历史审计读取”是否分开，不能为了追溯重新公开已撤销资料。

正文目前是数据库明文。Embedding 向上游外发片段，AI 整理可能外发更多资料；启用前确认授权、范围与预算。正则脱敏和人工审核不是完整 DLP。检索结果只能作为非可信参考，不能覆盖 Agent 指令、执行授权或实时检查。[OWASP RAG 安全指南](https://cheatsheetseries.owasp.org/cheatsheets/RAG_Security_Cheat_Sheet.html)

## 知识、记忆、任务状态

| 类型 | 示例 | 管理要求 |
| --- | --- | --- |
| 知识 | 某软件版本的故障处理方法 | 审核、证据、版本、适用范围、授权共享 |
| 记忆 | 用户语言偏好、项目部署约定 | 主体、同意、更正、有效期、冲突和遗忘 |
| 任务状态 | 当前步骤、检查点、审批 | core 任务生命周期，不自动变长期知识 |

可复用底层组件，不共用发布/权限语义。记忆部署归属另行设计，不自动由任务创建画像。

## 次序与验收

一期先独立管理入口/鉴权，落实归属权限、来源/适用性与索引规则；保留 core 公共协议兼容。开放正式多人使用前完成隔离测试、生产迁移/检索、任务监控、删除保留和恢复。测试 API/Worker 配置不同、换模型/维度、旧索引回退、下架和备份恢复，不能只验证正常路径。

AI 整理、多来源自动合并、文件解析、记忆后续实施；对象存储、共享队列、多副本按实际需求引入。
